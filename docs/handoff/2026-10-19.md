# Handoff: 2026-10-19

## Instances: one Codemm, several courses

**What changed:**
- **#200, one Codemm per profile.**
  - `boot.ts` is the new entry. It loads `main.ts` only while it holds Electron's single-instance lock, so a second launch quits before it starts any job, install or cleanup.
  - The open Codemm restores and focuses its window. A launch while it quits opens Codemm again once it has stopped, unless Restart to update's installer will open it.
  - e2e launches and the packaged test get their own profile.
- **#203, several courses** (DESIGN §4.13).
  - `courses` in `desktop.json` holds every approved course; `approved` is the course on screen. The sidebar lists the courses, with New course.
  - Per course in `live.ts`: its own stall, setup, foreground lane, background queue and tutor turns.
  - Across courses, one track build and one author job at a time.
  - Job progress reaches the window only for the course on screen, research and the draft.
  - A Docker stall ends once Check this computer passes; a Docker or disk stall ends once that course's check, Try it or install succeeds.
