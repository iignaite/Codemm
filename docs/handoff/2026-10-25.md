## Framework activity failures: reproduction matrix

**What was run**:
- **Harness.** The desktop's own job pipeline, driven headlessly: its briefs, launch arguments, stream parsers and `runJob`, with core's `installProposal`. The flow was research, lesson, setup (up to 5 proposals), then one or two activities.
- **Isolation.** Every run used a fresh `CODEMM_HOME`, workspace and agent folder, with the owner's subscriptions and no API-key environment variables.
- **Models.** Codex gpt-5.6-luna for every framework. Claude Sonnet and Codex gpt-6-luna to tell model limits apart from Codemm causes. Cursor couldn't run: the free plan's usage was exhausted.
