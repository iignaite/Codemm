# 2026-10-24

## Installing Cursor for the learner

**What changed**: Codemm installs Cursor's CLI on macOS and Windows, as it already does Claude Code and Codex (`desktop/src/main/agentInstall.ts`, DESIGN (desktop) §3.1). It downloads Cursor's own script (`https://cursor.com/install`, or `?win32=true` on Windows), allowing only https hops on `cursor.com` and `downloads.cursor.com`, capped at 1 MB. It runs the script as a file: `/bin/bash <file>`, or `powershell -NoProfile -NonInteractive -ExecutionPolicy Bypass -File <file>`, with the 15-minute timeout. Then `find('cursor-agent')` must succeed, and the Node.js that runs Cursor's code must carry its signer's signature: the `node` beside the macOS launcher (Apple team `HX7739G8FX`, the Node.js Foundation), or the `node.exe` Codemm starts on Windows (Authenticode `O=OpenJS Foundation`, read from Cursor's 2026.10.22 Windows package). Cursor signs nothing itself and publishes no checksum, so this check is weaker than Claude Code's; DESIGN says so. Codex and Cursor now share one script runner. A script that exits 0 but leaves nothing Codemm can find is offline when its output says so (Cursor's PowerShell script doesn't stop on errors), else failed. "could not be resolved" (PowerShell 5.1's offline message) counts as offline, for Codex too.

**Verified**: desktop typecheck and `agentInstall.test.ts` on macOS. New tests cover the hosts, both argument arrays, the timeout, the signature checks (unsigned, wrong signer), offline with exit 1 and with exit 0, a failed or timed-out script, and nothing found after the script, which means failed. Two existing assertions changed because they encoded the old behavior: Cursor's `canInstall` is now true on macOS and Windows. `codesign` with the requirement passes on the real `node` of an installed Cursor (2026.10.16-e3cb207); its `cursor-agent-sea` is unsigned.

**Not verified**: a real Cursor install through Codemm on either OS. On Windows, `find('cursor-agent')` succeeds only once the Cursor launcher PR (#227) and the lookup PR (#228, `%LOCALAPPDATA%\cursor-agent`) are in. Until then, Codemm's Windows install of Cursor ends as failed. `Get-AuthenticodeSignature` returning `Valid` for Cursor's `node.exe` on a real PC is also unconfirmed.
