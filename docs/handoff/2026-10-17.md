# Handoff: 2026-10-17

## Summary

Codemm 1.0 replaces the v1 desktop app with a harness that your own coding agent drives. Branch `release/1.0`.

- **Design.** The spec is `docs/DESIGN.md`, revised through three Astra design reviews; the review log is §13. The acceptance criteria are A1–A16.
- **Implementation.** `src/` holds the core (`files`, `schemas`, `grading`, `sandbox`, `judge`, `gates`, `learner`, `store`, `app`) and the entry points (`cli`, `mcp`, `init`, `hook`, `doctor`). Astra's milestone reviews (F01–F17 and the re-check) are resolved.
- **v1 removed.** `docs/MIGRATION.md` lists v1's data locations and the verified rollback to `5e3f3a7`.
- **CI.** GitHub Actions runs the type check, build and full suite on Linux with Docker required.

## How to run

```bash
npm ci && npm run build && npm test
npm link && codemm doctor
```
