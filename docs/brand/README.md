# Codemm brand assets

| File | Use |
| --- | --- |
| `codemm-logo.svg`, `codemm-logo.png` | Logo for light backgrounds (navy wordmark) |
| `codemm-logo-dark.svg`, `codemm-logo-dark.png` | Logo for dark backgrounds (light wordmark) |
| `codemm-mark.svg` | The chevron "C" alone, for icons and avatars |
| `social-preview.png` | GitHub social preview, 1280×640 |

The PNGs are 1200×260 with a transparent background. Prefer the SVGs wherever they're supported.

**Colors**

| Name | Value |
| --- | --- |
| Navy (wordmark) | `#0E2754` |
| Light (wordmark on dark) | `#F3F6FB` |
| Green gradient (mark), top to bottom | `#3DDB6C` → `#17B04B` |

The logo is a vector redraw of the original Codemm logo. The wordmark is Poppins SemiBold converted to outlines, so no font is needed to display it. Poppins is © the Poppins Project Authors and licensed under the [SIL Open Font License 1.1](https://openfontlicense.org).
