Opening a beta build

Beta builds aren't signed yet, so the first launch takes one extra step.

Mac
Open Codemm once, then choose System Settings, Privacy & Security, Open Anyway.
Windows
In the SmartScreen prompt, choose More info, then Run anyway.

Before you start

Sign in to Claude Code, Codex or Cursor. If Docker isn't on this computer, Codemm installs it for you.

Every email from Codemm has a link to remove your email.
