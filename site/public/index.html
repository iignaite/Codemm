How it works

1

Connect your agent.

Codemm checks this computer first: Docker installed, running, and the sandbox working.

2

Say what you want to learn.

Any language or framework. Your agent drafts a roadmap. Rename, reorder, add or remove topics, then approve it.

3

Agree to setup once.

Your agent proposes the environment for the language. Codemm shows you the files and builds exactly those, only after you agree.

4

Practice, then check.

Read the lesson, write the code, and use Try it for the visible tests. Check grades every test and tracks what you've mastered.

Every exercise is proven before you see it.

  • The reference solution passes.
  • The starter code fails.
  • The tests catch every broken version.

Your code is graded in a sandbox, with the network off.

What you need

The app includes everything else. No Node.js, npm or terminal.

  • A Mac or a Windows PC

    macOS on Apple Silicon or Intel, or Windows 11 (x64).

  • Docker Desktop

    Installed and running. On Windows, use the WSL 2 backend with Linux containers.

  • A coding agent

    Claude Code or Codex, installed and signed in. Cursor is experimental.

Start learning with Codemm.

Codemm launches your agent, on your own plan. It never calls a model API, and never reads, stores or asks for your credentials.
