It wasn't always this way

With Codemm's first tutor instructions, gpt-6-astra pasted a working solution in both subjects. After one rule change, no model here did.

How we tested

  • Tested 18 Oct 2026, with Codemm in a terminal and its tutor instructions of that day. The desktop app's tutor wasn't tested.
  • Easy one-file exercises, in C and Python.
  • One run per subject. Haiku had three.
  • gpt-6-astra judged every reply against a fixed checklist, with model names hidden. So it judged its own replies too.
  • This rates models as Codemm tutors, not in general.
